# КОНТУР БЕЗ ОШИБОК (записал Claude, 09.11.2026, по решению владельца)

Обязательно для **всех PR с кодом** в `meta6-lab` и `meta6` (ChatGPT, Codex, Claude, любые агенты).
Цель: ни одна пойманная ошибка не повторяется, а работа гарантированно доходит до [ФИНИША](../09-platforma/FINISH.md).

## К1. Задача — не больше ~1 часа
Больше — разбить на части. Одна задача закрывает один пункт FINISH.md или его часть.

## К2. Две попытки
Если задачу не принял Claude после 2 промптов — её доделывает Claude. Третьего промпта на ту же задачу нет.

## К3. ВЕЧНАЯ ЛОВУШКА
Каждая найденная ошибка (кем угодно: Claude, бот, сам агент) → строка в [OSHIBKI.md](../../OSHIBKI.md) **+ новая автоматическая проверка или мутация, которая ловит именно эту ошибку**.
Без ловушки ошибка не считается исправленной. Все ловушки (`scripts/**/mutate-*.mjs`) прогоняются на каждом PR — повторить старую ошибку невозможно.

## К4. ЗАПРЕЩЁННЫЕ ХИТРОСТИ
1. Код, который ведёт себя иначе для тестов, CI или части клиентов (флаги `legacy*`, `isTest*`, проверка имени теста, `process.env.CI` в игровом/MCP-коде).
2. Захардкоженные данные там, где задан источник (список игр, компонентов, уровней).
3. Молчаливое ослабление или удаление существующей проверки (убран `assert`, уменьшено ожидаемое число, проверка пропущена).
4. «100%», «готово», «зелёное» без реального теста, который это проверяет.

## К5. Ловушка-обман к каждой новой проверке
Каждая новая проверка → минимум 3 мутации (испорченные копии кода), **одна из них — «обман»**: хардкод или особый случай под тест.
Проверка обязана упасть на каждой мутации. Мутации лежат рядом: `mutate-<имя>.mjs`.

## К6. Старая проверка мешает → менять открыто
В описании PR строка `ПРОВЕРКА ИЗМЕНЕНА: <что и почему>`. Подгонять код под старую проверку запрещено (К4.1).

## К7. Еженедельный разбор
Раз в неделю: прочитать OSHIBKI.md, найти повторяющиеся виды ошибок, сделать PR с новой автоматической защитой (в охраннике `scripts/kontur/guard.mjs`).

## К8. Нашёл ошибку → исправь сам
Обязан сам исправить и только потом отчитаться. Отчёт «нашёл ошибку» без исправления запрещён.

## К9. Доказательства
Каждое утверждение («сделано», «проверка прошла», «слито») — со ссылкой на PR, SHA и прогон Actions. Без ссылки не принимается.

## К10. Выборочные ловушки Claude
Claude проверяет принятые PR своими тайными мутациями. Каждая не пойманная мутация → строка в OSHIBKI.md и новая ловушка по К3.

## К11. Обрыв сессии ничего не стоит
Сессия ChatGPT может оборваться («время ожидания истекло», слишком длинный разговор). Поэтому: коммит и пуш в свою ветку **не реже чем каждые 10 минут** работы; после каждого шага — одна строка в описании PR «сделано / дальше». Новая сессия продолжает **только по PR и ветке на GitHub**, не по памяти чата. Зависшую работу сторож ZANYATO watch через 3 часа освобождает, и её подхватывает следующая автозадача — продолжая с последнего коммита ветки. Долгую работу поручать автозадачам, а не браузерному чату: автозадача перезапускается сама. Не ждать долгих прогонов в одной сессии: запустил CI — запиши в PR «жду прогон <ссылка>» и заканчивай; следующий запуск проверит итог.

## К12. КАЧЕСТВО КОДА (ревью Claude 10.11.2026)
Полный разбор — [docs/CODE_QUALITY_2026-11-10.md](../../docs/CODE_QUALITY_2026-11-10.md). В каждом PR с кодом:
1. **Зелёный пункт проверяется на main, а не только в PR.** Проверка, которая смотрит формат, но не результат (адрес не открыт, индекс не пересобран), — не проверка (OSHIBKI №17).
2. **Не копировать.** Нельзя добавлять вторую копию файла > 1 МБ, папки `*-copy`, `node_modules`, ещё один `three.module.js`. Общее — в `shared/`.
3. **Не вшивать адреса и версии в код.** Адрес сайта и версии библиотек — из одной настройки (`package.json`, переменная окружения).
4. **Без интернета.** Новая или изменённая игра не берёт код и шрифты с CDN.
5. **Читаемо.** Новый код: отступы, строка ≤ 120 символов, без пустого `catch{}` (ошибку вывести или объяснить комментарием).
6. **Новая папка — только если такой по смыслу ещё нет** (эталоны — только `reference/`).
7. **Новый workflow — только с `paths:`, `concurrency:` и `timeout-minutes:`**; сначала проверить, нельзя ли добавить шаг в существующий.
Нарушение, найденное Claude или ботом, = строка в OSHIBKI.md и ловушка (К3).

## Чек-лист перед PR
- [ ] задача ≤ 1 часа, закрывает пункт FINISH.md: ___
- [ ] мутации прогнаны, включая «обман» (К5)
- [ ] старые проверки не ослаблены, или есть строка `ПРОВЕРКА ИЗМЕНЕНА:` (К6)
- [ ] если исправление — строка в OSHIBKI.md + ловушка (К3)
- [ ] ссылки: SHA, прогон Actions (К9)
