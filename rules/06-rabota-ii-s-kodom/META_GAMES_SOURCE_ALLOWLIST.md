# META GAMES — эталонные источники игрового кода и ассетов (решение владельца 06.11.2026)

**Обязательное правило для Claude, ChatGPT, Codex, генераторов и всех агентов META GAMES.** Действует при создании новых игр, сборке контента, копировании, комбинировании и расширении игрового кода. Не требует изменения уже опубликованных игр.

## 1. Пять исходных эталонов

Для повторного использования **игрового кода и ассетов** разрешены пять исходных игр в `mpaykin1/meta6`:

| Эталон | Канонический путь |
| --- | --- |
| Twilight Island | `observer-world-en-v7/` |
| Ashen Path | `ashen-sumerek/` |
| Underwater World | `underwater-world/` |
| Three Worlds | `three-worlds-game/` |
| Veil Terraces | `meta-games-worlds/veil-terraces/` |

Можно переиспользовать, комбинировать и расширять модели, текстуры, анимации, шейдеры, звуки, игровые механики, фрагменты кода и остальные оригинальные компоненты. Эталоны нельзя ломать ради заимствования.

## 2. Все игры Claude — автоматически новые эталоны и кода, и ассетов

**Любая игра, созданная Claude и загруженная в META GAMES, автоматически дополняет эталонную библиотеку.** Это касается **как уже загруженных, так и всех будущих игр Claude**; дополнительного ручного решения владельца для каждой новой игры не требуется.

- Сразу после подтверждённой загрузки игры Claude в `mpaykin1/meta6` можно переиспользовать **весь её оригинальный игровой код и все её собственные ассеты**: механики, модули, функции, шейдеры, графику, модели, анимации, музыку и звуки.
- Изменять, расширять, комбинировать и переносить код Claude в следующие игры **разрешено**. Каждая новая подтверждённая игра Claude пополняет библиотеку эталонов автоматически.
- Подтверждение авторства и загрузки: GitHub PR/коммит, конкретная папка игры и запись о том, что исходники игры созданы/загружены Claude. Пометка `generated` без связи с Claude недостаточна. Уже существующие игры, например Witness Vault и Generated Confluence Vault, включаются **при подтверждении**, что они сделаны Claude.
- Если игра Claude содержит **сторонние** ассеты или код с неподтверждёнными правами повторного использования, эти чужие компоненты не разрешены до проверки; остальные оригинальные компоненты Claude сохраняют статус эталона. Правило не подменяет лицензию третьих лиц.

## 3. Запрет остальных доноров

Игровые ассеты и фрагменты игрового кода из **других игр**, демо, альтернативных веток, ассет-паков, архивов и интернета не использовать как источники META GAMES без отдельного прямого разрешения владельца. Публикация игры на портале или в GitHub без подтверждения, что её создал Claude, **не делает её эталоном**.

## 4. Исполнение

1. Записывать для каждого заимствования имя игры, исходный путь и версию/коммит. Разрешённые источники: пять исходных эталонов **плюс все подтверждённые игры Claude**.
2. Для каждой игры Claude при загрузке обновлять каталог источников, чтобы её собственные игровые исходники и ассеты были доступны генератору в следующих сборках; не ждать ручного подтверждения владельца.
3. Не путать **игровой код и ассеты** с инфраструктурой: семь движков World_server, сборщик, рендерер, сервисные и библиотечные зависимости продолжают использоваться в конвейере и не расширяют список игровых доноров.
4. Решение владельца касается оригинальных материалов эталонных игр. Права сторонних зависимостей проверять через `ASSET_INDEX.json` / `RIGHTS_REVIEW.json`; не устанавливать ложный `rights_verified` или `reuse_allowed`.
5. Любой другой источник игрового кода и ассетов может быть добавлен только новым прямым решением владельца.

**Приоритет:** это специальное правило META GAMES уточняет общие инструкции `REUSE.md`, `graf.md` и другие старые списки доноров **только для новых игр META GAMES**. Для остальных проектов действуют собственные правила.
