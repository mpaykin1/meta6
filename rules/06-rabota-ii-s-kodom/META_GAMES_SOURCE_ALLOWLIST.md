# META GAMES — разрешённые источники игрового кода и ассетов (решение владельца 06.11.2026)

**Обязательное правило для Claude, ChatGPT, Codex, генераторов и всех агентов META GAMES.** Применяется к созданию новых игр META GAMES, сборке контента, копированию, комбинированию и расширению существующего игрового кода. Не требует изменения уже опубликованных игр.

## 1. Пять единственных эталонов для повторного использования игрового кода и ассетов

Разрешено брать **игровые ассеты и фрагменты игрового кода** только из следующих пяти игр в `mpaykin1/meta6`:

| Эталон в META GAMES | Канонический путь в репозитории |
| --- | --- |
| Twilight Island | `observer-world-en-v7/` |
| Ashen Path | `ashen-sumerek/` |
| Underwater World | `underwater-world/` |
| Three Worlds | `three-worlds-game/` |
| Veil Terraces | `meta-games-worlds/veil-terraces/` |

Эти пять игр — **закрытый список эталонов**: можно переиспользовать их модели, текстуры, анимации, эффекты, звуки, шейдеры, механики, обработчики событий и части реализации, а также расширять и адаптировать их для новой игры. Новые оригинальные реализации и соединительный код писать можно. Эталоны не изменять ради заимствования. Копии, альтернативные версии и другие игры автоматически в список не входят.

**Запрещено** брать чужие игровые ассеты или заимствовать игровой код из любых других игр, веток, демо, архивов, ассет-паков и интернет-источников для новых игр META GAMES. Игры, уже размещённые на портале, сами по себе не становятся эталонами. В частности, Witness Vault и Generated Confluence Vault не входят в перечисленные пять.

## 2. Будущие игры, загруженные Claude: разрешены их ассеты, но не код

**Дополнительный, пополняемый источник только для ассетов:** все будущие игры, которые **Claude фактически загрузит** в `mpaykin1/meta6` для META GAMES после принятия этого правила.

- После подтверждённой загрузки/слияния игры Claude её **собственные ассеты** можно брать в другие игры META GAMES: графику, модели, текстуры, спрайты, звуки, анимации и прочие медиа.
- Авторство или загрузку **нужно подтвердить** по конкретному PR/коммиту, пути игры и источнику ассета. Одной пометки «generated» или факта публикации игры недостаточно.
- **Код и механики** игр Claude не становятся новым источником копирования: игровые фрагменты кода по-прежнему разрешено брать **только из пяти эталонов**.
- Если внутри игры Claude находится импортированный сторонний ассет с неподтверждённым правом на повторное использование/распространение, этот ассет **не разрешён** до проверки прав.

## 3. Порядок применения

1. Для каждого перенесённого фрагмента кода или ассета указывать оригинальную игру, путь и при необходимости коммит. Источник должен относиться к пяти эталонам; для ассета Claude — к подтверждённой будущей загрузке.
2. Не применять правило ко всем играм репозитория по умолчанию: **разрешён только перечисленный источник**, а не любая папка, похожее название или копия.
3. Не путать **код игровой механики/контента** с инфраструктурой платформы: существующие семь движков World_server, сборщик, рендерер, библиотечные и сервисные зависимости остаются доступными для работы конвейера, но не дают права импортировать из других игр ассеты и игровые реализации.
4. Решение владельца разрешает использование **собственных оригинальных компонентов** указанных игр; при известных чужих зависимостях сохраняются проверки `ASSET_INDEX.json` / `RIGHTS_REVIEW.json`. Публичность файла не доказывает лицензию. Не проставлять ложный `rights_verified` или `reuse_allowed`.
5. Если происхождение ассета или игрового кода не подтверждено, **не использовать**. Расширение списка эталонов игрового кода возможно только новым прямым решением владельца.

**Приоритет:** это специальное правило META GAMES уточняет общие инструкции `REUSE.md`, `graf.md` и другие старые списки доноров **только для новых игр META GAMES**. Для остальных проектов действуют их собственные правила.
