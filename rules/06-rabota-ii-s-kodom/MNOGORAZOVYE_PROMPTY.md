# МНОГОРАЗОВЫЕ ПРОМПТЫ И ПОСТОЯННОЕ РАЗВИТИЕ (правило владельца, 11.11.2026)

Действует для **каждого** промпта и задания ChatGPT, автозадач и любых ИИ-агентов по МГ и МГЛ — в том числе для уже выданных промптов: они читают этот файл через AGENTS.md.

## 1. Многоразовость
- Один и тот же промпт можно прислать повторно без изменений сколько угодно раз (после зависания, в новый чат, на следующий день).
- Прогресс хранится в файле на GitHub (`reports/<задача>/PROGRESS.md` в main), а не в памяти чата. Сохранять после каждого шага.
- Повторный запуск: прочитать прогресс → пропустить сделанное → продолжить с первого несделанного шага.
- Каждая взятая задача — строка в ZADACHI.md (без дублей).

## 2. Развитие вместо «всё готово»
Запуск никогда не заканчивается фразой «делать нечего». Когда основная работа задания сделана, тот же запуск переходит в **цикл развития**:
1. **Новый материал с прошлого раза.** В PROGRESS.md хранится метка «обработано до» (SHA, номер прогона, дата). Взять всё новое после метки: исправления Claude, revert-коммиты, красные прогоны на main, PR, закрытые без слияния, новые строки DLYA_CLAUDE.md и OSHIBKI.md, провалы бота-проходчика. Каждый случай → правило одной фразой + автоматическая ловушка + строка в OSHIBKI.md. Сдвинуть метку.
2. **Повтор ошибки = слабая ловушка.** Если ошибка, для которой уже есть правило, случилась снова — ловушку усилить, а не просто записать ещё раз.
3. **Самоэкзамен, если нового материала нет:** (а) взять 3 недавно слитых PR и проверить их строго по чек-листу проверяющего; найденный настоящий дефект — исправить и поставить ловушку; (б) охота на мутантов: придумать поломку охраняемого кода, которую текущие ловушки НЕ ловят; нашёл — добавить ловушку.
4. **Улучшить сам навык:** обновить чек-лист проверяющего (`rules/06-rabota-ii-s-kodom/CHEKLIST_PROVERYAYUSHCHEGO.md` в meta6-lab): добавить пункт, который поймал бы найденное; убрать пункт, который ни разу ничего не поймал и только тратит время.
5. **Счёт:** строка в таблице «Развитие» в PROGRESS.md: дата | новых правил | новых ловушек | найдено мутантов-беглецов | повторов ошибок | пунктов, ждущих Claude. Цифры должны показывать, становится ли лучше.

Минимум каждого запуска — **одно измеримое улучшение с доказательством** (ссылка на коммит, прогон или PR). Если и новый материал, и самоэкзамен ничего не дали — написать, что именно проверено (ссылки), а не «всё в порядке».

## 3. Навык живёт в файлах
ChatGPT не помнит прошлые чаты. «Научился» = записано правило, стоит ловушка, обновлён чек-лист. Чему не стоит ловушка — то не выучено.

## 4. Остальные правила промптов — без изменений
Нашёл ошибку — сам исправь и только потом отчитывайся. Каждое утверждение — со ссылкой (SHA, прогон, PR). Отчёт владельцу — только «осталось сделать», после того как сделано всё возможное самому. Защищённое (бот, проверки, охранники, сторожа, workflow, существующие эталоны) — не ослаблять; изменения — только как «решение на подпись Claude».
