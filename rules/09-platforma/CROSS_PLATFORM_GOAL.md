# META GAMES — кроссплатформенная цель (решение владельца 06.11.2026)

**КОНЕЧНАЯ ЦЕЛЬ:** одна игровая вселенная META GAMES — три официальных способа запуска: независимый Web (GitHub Pages), Android (Google Play), Windows (Steam). Все игры создаются из разрешённых эталонов и общего склада `shared/`, с тем же исходным HTML/JavaScript/Three.js/WebGL/GLSL-кодом. Это **дополнение**, а не замена основной защищённой цели [META_GAMES_PLATFORM.md](META_GAMES_PLATFORM.md) (§1–13). Подробная спецификация выпуска Steam — [STEAM_DISTRIBUTION.md](STEAM_DISTRIBUTION.md).

## Обязательные требования

1. Одна каноническая версия каждой игры и каждого разрешённого ассета; никаких самостоятельных форков игрового кода под магазин. Отдельные только оболочки и адаптеры платформы.
2. Web продолжает работать по существующему адресу, без изменения принятых оригиналов и без новых платных сервисов.
3. Android: локальный игровой пакет в Capacitor/WebView, сенсорное управление, сохранения; целевой SDK не ниже API 36 по требованиям Google Play с 31.08.2026, публикация подписанного Android App Bundle через Play Console.
4. Windows/Steam: Electron/Chromium с локальными игровыми файлами и WebGL, управление клавиатурой/мышью/геймпадом по возможностям каждой игры. Дистрибутив загружается через SteamPipe.
5. Все миры, представленные в каталоге, должны запускаться из единого приложения без открытия внешнего браузера. Общий профиль, трофеи, двери между мирами и сохранения должны работать между играми; платформенно-зависимое облачное сохранение добавляется только при готовом локальном контракте.
6. Автоконструктор из семи движков World_server, разрешённый каталог исходников, R1–R11, U1–U6, ежедневное автоулучшение и бот-проходчик сохраняются. Бот обязан проверять запускаемые игровые сборки и проходимость перед выпуском; зелёный CI не означает художественный OWNER PASS.
7. Для Steam **не использовать рекламную бизнес-модель**: отключить Adsterra, Playgama rewarded/interstitial и все остальные рекламные вызовы, включая рекламу внутри игрового процесса. Steam-версия без рекламы; подходящую монетизацию определяет владелец отдельно. Для Android реклама возможна только после интеграции совместимого SDK, политики приватности и проверки правил Google Play.
8. Новые игры и обновления общего кода доступны трём каналам из одного источника. Обновление установленного приложения подчиняется правилам каждого магазина; не обещать самостоятельной подмены исполняемого кода.
9. Для обеих площадок: права на игровые материалы и все сторонние зависимости, раскрытие использования генеративного ИИ, возрастные оценки, приватность, качество, отсутствие мошеннической рекламы, доступность без обязательного перехода на сайт.
10. Защищённые эталоны, основной файл цели, каркасы Claude, GitHub guard, пять автозадач и Netlify не изменять без отдельного предусмотренного разрешения владельца.

## Что считается готовым

- Web: прежний портал и все принятые игры открываются без регрессий.
- Android: реально установленный Android-пакет с локальным запуском каждого мира, работающим тачем/звуком/сохранениями, без WebView-сбоев; собранный подписанный AAB проходит требования Play Console.
- Windows: установленный пакет с локальным запуском каждого мира, игровыми контроллерами, рабочими сохранениями, корректным GPU/WebGL; рекламные SDK отсутствуют либо гарантированно неактивны; Steam review и SteamPipe успешно пройдены.
- Общая система сохранений/достижений проверена между разными мирами; бот проходит уровни на мобильном и настольном экране.
- Окончательная публикация требует одобрения владельца, аккаунтов площадок, проверки личности, налоговых/платёжных данных и одобрения магазинов. Наличие скриптов сборки — **не** статус «опубликовано».

## Выполняется сейчас

Первый инфраструктурный этап: папка `platforms/` собирает локальный Web-контент текущих миров, готовит Electron Windows package и Capacitor Android project; отдельный запускаемый вручную GitHub Actions workflow собирает установочные кандидаты. Исходные игры и сайт остаются без изменений.

Следующие этапы: совместимость всех игровых зависимостей и рекламы с store-сборкой → единый контракт сохранений и дверей между мирами → реальные прогоны всех игровых миров на Android/Windows → подпись и подготовка страниц площадок → публикация по решению владельца.

Официальные требования: [Google Play target API](https://developer.android.com/google/play/requirements/target-sdk), [Capacitor Android](https://capacitorjs.com/docs/android), [Steam Direct](https://partner.steamgames.com/steamdirect/), [SteamPipe](https://partner.steamgames.com/doc/sdk/uploading).
