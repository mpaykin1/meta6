# META GAMES — кроссплатформенная цель (решение владельца 06.11.2026)

**КОНЕЧНАЯ ЦЕЛЬ:** одна игровая вселенная META GAMES — три официальных способа запуска: независимый Web (GitHub Pages), Android (Google Play), Windows (Steam). Все игры создаются из разрешённых эталонов и общего склада `shared/`, с тем же исходным HTML/JavaScript/Three.js/WebGL/GLSL-кодом. Это **дополнение**, а не замена основной защищённой цели [META_GAMES_PLATFORM.md](META_GAMES_PLATFORM.md) (§1–13). Подробная спецификация выпуска Steam — [STEAM_DISTRIBUTION.md](STEAM_DISTRIBUTION.md). Подробный план автоматического пополнения Android-приложения и выпуска обновлений в Google Play — [ANDROID_DISTRIBUTION.md](ANDROID_DISTRIBUTION.md).

## Обязательные требования

1. Одна каноническая версия каждой игры и каждого разрешённого ассета; никаких самостоятельных форков игрового кода под магазин. Отдельные только оболочки и адаптеры платформы.
2. Web продолжает работать по существующему адресу, без изменения принятых оригиналов и без новых платных сервисов.
3. Android: локальный игровой пакет в Capacitor/WebView, сенсорное управление, сохранения; целевой SDK не ниже API 36 по требованиям Google Play с 31.08.2026, публикация подписанного Android App Bundle через Play Console. Для нового личного аккаунта Google Play (созданного после 13.11.2023) перед выходом в production обязателен закрытый тест (не меньше 12 тестировщиков, 14 дней подряд) — это делают люди, не ИИ; аккаунт организации от него освобождён. Capacitor 8.6.0 требование API 36 выполняет (проверено 06.11.2026).
4. Windows/Steam: Electron/Chromium с локальными игровыми файлами и WebGL, управление клавиатурой/мышью/геймпадом по возможностям каждой игры. Дистрибутив — распакованная папка (`electron-builder --win dir`, не `portable`), загружается через SteamPipe.
5. Все миры, представленные в каталоге, должны запускаться из единого приложения без открытия внешнего браузера. Общий профиль, трофеи, двери между мирами и сохранения должны работать между играми; платформенно-зависимое облачное сохранение добавляется только при готовом локальном контракте.
6. Автоконструктор из семи движков World_server, разрешённый каталог исходников, R1–R11, U1–U6, ежедневное автоулучшение и бот-проходчик сохраняются. Бот обязан проверять запускаемые игровые сборки и проходимость перед выпуском; зелёный CI не означает художественный OWNER PASS.
7. Для Steam **не использовать рекламную бизнес-модель**: отключить Adsterra, Playgama rewarded/interstitial и все остальные рекламные вызовы, включая рекламу внутри игрового процесса. Steam-версия без рекламы; подходящую монетизацию определяет владелец отдельно. Правила RETENTION, которые опираются на рекламу (R5 воскрешение за rewarded, R6 interstitial на «Ещё раз»), в Steam-сборке заменяются тем же действием без рекламы (воскрешение по кнопке, «Ещё раз» сразу), а не удаляются вместе с кнопкой. Для Android реклама возможна только после интеграции совместимого мобильного SDK, политики приватности и проверки правил Google Play. **Механизм отключения для обоих магазинов один:** `prepare-web.mjs` вставляет в каждую игру флаг `window.META_GAMES_NATIVE={platform, adsEnabled:false}`, адаптер R5/R6 игры его читает (сейчас — ни одна игра не читает, в Android флага нет вовсе; проверка 06.11.2026).
8. Новые игры и обновления общего кода доступны трём каналам из одного источника. Обновление установленного приложения подчиняется правилам каждого магазина: в Google Play — новый AAB с большим `versionCode`, в Steam — новый билд SteamPipe (публичную ветку `default` переключает человек). Скачивание игр по сети в обход магазина не делать без отдельного решения владельца (подробно — [ANDROID_DISTRIBUTION.md](ANDROID_DISTRIBUTION.md) §1).
9. Для обеих площадок: права на игровые материалы и все сторонние зависимости, раскрытие использования генеративного ИИ, возрастные оценки, приватность, качество, отсутствие мошеннической рекламы, доступность без обязательного перехода на сайт.
10. **Один общий каталог** для Web, Steam и Android: `platforms/catalog.json` (поля `steamEligible`, `androidEligible`, `botStatus`, `rightsStatus`). Отдельные `steam/catalog.json` или Android-список не заводить. Одна оболочка: уже существующая `platforms/` (Electron `platforms/desktop/`, Capacitor `platforms/capacitor.config.json`); второй проект оболочки не создавать.
11. **Только бесплатно.** Сборка, CI и хостинг — бесплатные тарифы. Платные шаги магазинов (Steam Direct $100 за приложение, регистрация Google Play $25 один раз) и шаги, которые делает только человек (личность, налоги, банк, тестировщики), — СТОП: ИИ доводит всё бесплатное до готовности и пишет владельцу одно сообщение «нужно ваше решение», без начала платного шага.
12. Защищённые эталоны, основной файл цели, каркасы Claude, GitHub guard, пять автозадач и Netlify не изменять без отдельного предусмотренного разрешения владельца.

## Что считается готовым

- Web: прежний портал и все принятые игры открываются без регрессий.
- Android: реально установленный Android-пакет с локальным запуском каждого мира, работающим тачем/звуком/сохранениями, без WebView-сбоев; собранный подписанный AAB проходит требования Play Console.
- Windows: установленный пакет с локальным запуском каждого мира, игровыми контроллерами, рабочими сохранениями, корректным GPU/WebGL; рекламные SDK отсутствуют либо гарантированно неактивны; Steam review и SteamPipe успешно пройдены.
- Общая система сохранений/достижений проверена между разными мирами; бот проходит уровни на мобильном и настольном экране.
- Окончательная публикация требует одобрения владельца, аккаунтов площадок, проверки личности, налоговых/платёжных данных и одобрения магазинов. Наличие скриптов сборки — **не** статус «опубликовано».

## Выполняется сейчас

Первый инфраструктурный этап: папка `platforms/` собирает локальный Web-контент текущих миров (проверено 06.11.2026: 10 игр, 47 МБ, без скриптов с CDN), готовит Electron Windows package и Capacitor Android project; workflow `.github/workflows/meta-games-native-build.yml` (запуск вручную и на PR, меняющие `platforms/`) собирает установочные кандидаты без подписи и без публикации. Исходные игры и сайт остаются без изменений.

**Автоматическое пополнение каталога пока не работает** (проверка Claude 06.11.2026). Что мешает и как исправить — по пунктам в [ANDROID_DISTRIBUTION.md](ANDROID_DISTRIBUTION.md) (этап 3) и [STEAM_DISTRIBUTION.md](STEAM_DISTRIBUTION.md) (§3): (1) новая игра не запускает сборку — нужен запуск на `push` в `main` по путям игр; (2) игры берутся из ссылок портала, а не из `platforms/catalog.json` с допуском; (3) Android-проект пересоздаётся каждый раз → `versionCode` всегда 1, Google Play отклонит обновление; (4) AAB не подписан; (5) Steam собирается как `portable` вместо папки; (6) полноэкранный режим в Electron запрещён; (7) реклама в Android не отключена, флаг `adsEnabled` игры не читают.

Следующие этапы: совместимость всех игровых зависимостей и рекламы с store-сборкой → единый контракт сохранений и дверей между мирами → реальные прогоны всех игровых миров на Android/Windows → подпись и подготовка страниц площадок → публикация по решению владельца.

Официальные требования: [Google Play target API](https://developer.android.com/google/play/requirements/target-sdk), [Capacitor Android](https://capacitorjs.com/docs/android), [Steam Direct](https://partner.steamgames.com/steamdirect/), [SteamPipe](https://partner.steamgames.com/doc/sdk/uploading).
