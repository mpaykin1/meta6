# Чек-лист универсальных правил для автоправки и бота META GAMES

Записано Claude 06.11.2026 по слову владельца. Это **рабочий список того, что платформа должна внести в каждую игру и как бот проверяет, что это внесено**. Полные тексты правил — в папках `rules/01…07` (оглавление — [AGENTS.md](../../AGENTS.md)). Цель платформы — [META_GAMES_PLATFORM.md](META_GAMES_PLATFORM.md) (разделы 7–10).

Как пользоваться:
- **Автоправка** берёт игру из очереди, проходит правила сверху вниз и вносит недостающее **только добавлением** (принятое владельцем не ломать, ассетов не убавлять).
- **Бот** проверяет каждую строку столбца «Как проверить» на телефоне (390×844) и на ПК. Строка без проверки — не считается сделанной.
- Пример игры, в которой большая часть уже внедрена, и честный статус по каждому правилу: [games/sumerki-i-pepel-2/README.md](../../games/sumerki-i-pepel-2/README.md).

## Правила и проверки

| # | Правило (папка) | Что должно быть в игре | Как проверить (бот / автоправка) |
|---|---|---|---|
| 1 | ЧИСТЫЙ ЭКРАН (01) | Во время игры только графика и кнопки-иконки; текст только в меню ☰ (правый верхний угол) и в коротких сообщениях об открытии/речи героя, которые сами гаснут. | Во время игры нет постоянных видимых текстовых узлов кроме меню; у каждой кнопки есть `aria-label` и нет подписи. |
| 2 | ПОСТЕПЕННО (02) | В заставке и на старте только земля, атмосфера и главная цель; в бою 1 враг и 1 оружие. Объекты открываются победами по одному, враги и оружие — по прогрессу. Сообщение об открытии ~6 с, по одному. Всё открытое — в меню ☰ по разделам. | На старте: 0 объектов и декора (трава, плитки, силуэты), 1 тип врага, 1 оружие. После N побед ровно одно новое открытие + сообщение + запись в меню. |
| 3 | Новинки вперемешку (02, решение владельца 05.11) | Новинки чередуются по видам (враг, объект, тайл, оружие, помощник, умение, погода, житель, тайник, музыка), два одного вида подряд не идут, после врага — польза. Только из ассетов, которые уже есть в игре. | Порядок открытий за запуск: нет двух одинаковых видов подряд; каждый пункт есть в описи ассетов игры. |
| 4 | ПОНЯТНАЯ ПОЛЬЗА (02) | Каждая вещь реально что-то даёт; сообщение «что сделать → что получишь»; срабатывание видно и слышно; новая вещь подсвечивается (луч, кольцо, стрелка), следующая — только после того, как игрок попробовал предыдущую; запись в меню с откатом и «где». | Для каждой вещи: механика срабатывает (меняется число/состояние), в момент срабатывания есть эффект и звук, текст меню совпадает с поведением. |
| 5 | БЕЗ ПОВТОРОВ (02) | Раскладка уровней и места предметов не повторяются ни между уровнями, ни между запусками; всё проходимо. | Два запуска подряд: раскладки различаются; бот проходит оба. |
| 6 | FIX ЭКРАН + УПРАВЛЕНИЕ НА ТЕЛЕФОНЕ (02) | Страница не тянется и не прокручивается; джойстик двигает героя, камера плавно следует; кнопки — иконки. | `scrollY = 0`, размер canvas не меняется при джойстике 10 с; герой движется, камера следует. |
| 7 | UNIVERSAL U1–U6 (02) | Вносить, где подходят по смыслу, только добавлением (решение владельца 06.11). | Для каждой внесённой U — отдельная проверка из UNIVERSAL_UPGRADES.md. |
| 8 | ЗВУК (03) | Музыка меняется по настроению и развивается вместе с прогрессом; нет резких, высоких, раздражающих звуков; нет монотонности. | Нет звуков выше ~4 кГц с резкой атакой на громкости эффектов; музыка меняет лад/слои при смене состояния. |
| 9 | ЛОР + ПОДПИСИ-ВОСПОМИНАНИЯ (04) | Для почти готовой игры: жуткое детство героя косвенно в уровнях, история от первого лица в конце, объяснение кругов 2, 3, 4…; короткие подписи-осколки памяти. | Есть экран истории в конце; подписи появляются и гаснут; бот доходит до конца круга 1 и начала круга 2. |
| 10 | ВИДИМО И ЭКОНОМНО (05) | Анимации и вычисления только там, где видно; вне кадра — дремлет (редкие проверки) или формула; каждое последствие видно (в кадре — эффект и звук, вне кадра — стрелка/метка на карте); бюджеты частиц и звуков; автоподстройка при просадке. | Вне кадра нет покадровых обновлений (счётчик вызовов); FPS p95 с открытыми новинками не хуже, чем без них; каждое событие вне кадра даёт указатель. |
| 11 | Работа ИИ с кодом (06) | Сначала готовое (REUSE), источник владельца, перенос целиком, опись из кода, «было N — осталось N», только запрошенное. | Число ассетов по описи не уменьшилось; принятое (ACCEPTED_BEHAVIORS) работает как раньше. |
| 12 | RETENTION R1–R11 (07, для Playgama) | Мгновенный старт, загрузка без текста, обучение без слов, подарок в первые секунды, rewarded-воскрешение, interstitial только на «Ещё раз», кнопки-иконки, телеметрия, пауза на P, версия сборки, `window.__INV()`. | Проверки из PLAYGAMA_RETENTION.md. |
| 13 | Бот-ручка (09) | `window.__META_BOT__` только показывает состояние: уровень/этап, всего этапов, где герой и цель, жив ли герой, пройден ли этап, какие кнопки есть. Ничего не двигает. | Ручка есть, поля заполнены, вызов не меняет игру. |
