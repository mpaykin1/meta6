# Остров сумерек — острова, биомы и сиды

**Канонический короткий пароль для любого нового чата:** `island-biomes`

**Играть:** https://mpaykin1.github.io/meta6/island-sumerek-biomes/

**Исходный HTML:** https://github.com/mpaykin1/meta6/blob/main/island-sumerek-biomes/index.html

**Инструкция по разработке:** https://github.com/mpaykin1/meta6/blob/main/island-sumerek-biomes/README.md

Отдельная игра на базе пользовательского `Остров сумерек (1)(6).html` и стандарта [graf](../graf.md). Не изменяет принятый Observer World V7, не заменяет его управляющую схему.

## Что реализовано

- Сохранён Three.js r160 WebGL-рендерер, перспективная камера, шейдер воды, маяк, 20 монет, арсенал 21 позиция (включая кулаки), враги, бой, HUD, движение WASD/стрелки, пробел, мышь, мобильные кнопки.
- **10 процедурных биомов**: классика, готика, неоновый Токио, футуризм, сакура, лёд, вулкан, грибной лес, пустыня, кристаллы.
- Сиды `?biome=gothic&seed=1604` и текстовые `?biome=tokyo&seed=Tokyo-2077`; Mulberry32 + FBM, числовые/строковые входы. Это собственный генератор, не Minecraft-паритет. При одинаковом сидe и версии создаётся одинаковый воксельный рельеф.
- Новые tile-атласы, иллюстрированные 2D props, 2.5D façades/billboards, GPU Three.Mesh landmarks, 2D спрайтовые анимации, анимированный 2.5D объект (скрещённые плоскости), сочленённый 3D персонаж с независимыми конечностями, анимированный 3D объект (кристалл/маяк/гриб).
- Тематическая настройка света, эмиссии, тумана; декоративные здания не заменяют исходную физику/коллизии.
- Самодостаточный `index.html` (графические атласы встроены как data URI). **Важно:** ESM импорты Three.js r160 загружаются с публичного jsDelivr CDN, нужен интернет.

## Проверки

`node tests/test-seeds.cjs` — детерминизм десяти биомов, разнообразие сидов и валидность генерации. `node tests/check-module.cjs` — извлечение и `node --check` игрового JS.

Приёмка — только по решению владельца **PASS** или **FAIL**. Успехи и ошибки не коммитить как оценки без его ответа. Автотесты не доказывают равенство графики эталону и реальный FPS iPhone 11. Временный технический коммит не равен PASS.

## Технические ограничения

Нет доказанных 60 FPS на реальном телефоне, нет подтверждённого pixel-perfect совпадения с эталоном, блокировка CDN остановит загрузку Three.js. Декоративные 3D-фигуры настоящие объёмные модели Three.Mesh/Group, но не rigged GLB и не участвуют в бою. Изображения-спрайтшиты содержат наборы поз; качество каждого перехода анимации требует визуального ревью.
