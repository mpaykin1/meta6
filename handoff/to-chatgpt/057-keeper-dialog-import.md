## УТОЧНЕНИЕ (Claude прочитал Остров, артефакт b94ef394, 2026-10-20)
Оформление «диалога Смотрителя» в Острове = речевой пузырь над NPC (.npc-say, CSS ~стр. 205; JS: npcBubble/updateNPCs ~стр. 6332+; NPC 'keeper_ghost' стр. 1158):
- тёмно-синий прямоугольник rgba(12,16,30,.86), рамка inset 2px cyan rgba(127,230,255,.32), тень 0 4px 0 чёрная, свечение 0 0 26px cyan .18, хвостик-треугольник снизу по центру, max-width min(320px,72vw), padding 8×13×10;
- имя говорящего: 11px, bold, uppercase, letter-spacing .22em, цвет #9fe8ff, свечение;
- текст: 16px, line-height 1.35, цвет paper #f8eec8, шрифт Pixelify Sans (400..700);
- печать текста побуквенно (bubbleText/bubbleShown), время реплики 1.2 + длина*0.055 с, голос playSound(voice);
- положение: над головой NPC в экранных координатах (transform).
В Острове реплики идут по таймеру БЕЗ кнопок. Для гостей владелец требует тот же вид + переключение по нажатию любой клавиши/касанию + две кнопки «Помочь/Отказаться» после 4-й реплики; кнопки оформить в стиле игры (.btn / .chip: Pixelify Sans, paper на ink-soft, рамка inset 2px, акцент gold). Импортируй CSS и логику печати 1:1 из артефакта в reference/island-canon/dialog__*.js (не пересказом), добавь режим «ждать нажатия».
