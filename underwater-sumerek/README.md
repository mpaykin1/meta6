# Остров сумерек + Затонувший город (подводный биом)

Основа — **артефакт владельца «Остров сумерек»** (`base-artifact-b94ef394.html`, 1:1, система паков/биомов). Подводный мир добавлен как
третий остров-пак `sunken` в меню «Остров»; остров `dusk` и `frost` не изменены.

- `pack.js` — пак `sunken`: биом (серо-жёлтые кубы: sand сверху, stone внутри, неровное дно `terrain.seabed`), подводная палитра, враги и мозг/тело `swimmer`.
- `uw_models.js` — GLB-враги (угорь, медузы, дрон, удильщик, хранитель-кракен) плавают по цепи `f.segs`: оружие, урон и хитбоксы Острова прежние.
- `city.js` — архитектура, флора, рыбы, батискаф Затонувшего города (GLB в `glb/`).
- `portal.js` — всплытие (держи прыжок) → берег Острова сумерек; зайти слишком глубоко на острове → нырок. HP, реликвии, оружие переносятся.
- Под водой: плавучесть (прыжок = вверх), липкое автонаведение (из three-worlds), кнопки Удар/Прыжок — пиксельные иконки.
- Сборка: `python3 patch.py` (из `base-artifact-b94ef394.html` → `index.html`). Нужны `pack.js`, `uw_models.js`, `city.js`, `portal.js`, `ico_*.svg`.
- Играть: открыть `index.html` через любой статический сервер (GLB грузятся как `glb/*.json`).
