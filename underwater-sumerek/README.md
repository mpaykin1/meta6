# Затонувший остров (underwater Остров сумерек)

Игра = `island-sumerek-biomes/index.html` + новый биом `sunken` (`?biome=sunken`, по умолчанию).
Оружие, бой, лут, HUD, мобильное управление — **те же, что в Острове сумерек** (не переписывались).

Что добавлено:
- рельеф: кубы жёлтые и серые (атлас из desert + серый dirt), неровное дно (`generateWorld`, ветка `UW`);
- вода: `SEA=-200` отключает всю логику поверхности, плавание: плавучесть, прыжок = всплытие (`physicsStep`), стены мира, пузырьки;
- враги: реальные GLB Затонувшего города (угорь, медузы, дрон, удильщик, щупальце кракена в роли босса) плавают по цепи `f.segs` Острова — урон и хитбоксы прежние (`uwfoes.js`, раздел 30b);
- кнопки Удар/Прыжок — пиксельные SVG-иконки (`icons.py`).

Как собрано: `patch.py` (применяется к `island-sumerek-biomes/index.html`, нужен `sunken_atlas.b64`), `uwfoes.js` вставляется перед разделом 31. Готовый результат — `index.html`.
Правило для ИИ: переиспользуй код Острова, не переписывай бой. Решение PASS/FAIL — только владелец.

Обновление: добавлен город (city.js): собор, виадук, арки, галеон, рыбы, батискаф, флора из ассет-пака Затонувшего города.
