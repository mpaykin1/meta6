# ABYSS GLOW — approved visual target from owner references (2026-10-23)

Status: **REFERENCE / TARGET**, not evidence that the game already renders this quality.

## Reference anatomy
- Vertical mobile composition, deep underwater Gothic ruins, cathedrals, pointed towers, multilevel viaducts and sunken sailing ships.
- Near-black navy/cyan atmosphere; very sparse high-intensity amber/orange emissive edges, windows, and bioluminescent organisms.
- Pixel-art / 2.5D foreground silhouette and selective warm highlights, layered depth, atmospheric fog and volumetric shafts from the surface.
- Small friendly luminous fish against gigantic dark architectural scale.
- Threat encounter: an enormous frontal mouth with independently readable curved glowing teeth; hero remains small and distinct.
- No UI text covering the playfield. Touch-only full-viewport navigation.

## Asset production backlog (do not change original owner HTML)
1. Build an atlas from ORIGINAL and generated assets with stable ids and dimensions, padding and extrusion. Validate alpha, bounds, mip bleed and normal-map orientation.
2. Create three independent parallax planes: near black masonry/shipwreck; mid-ground viaduct/arches; far cathedral silhouette. Separate animation layers, not a flattened screenshot.
3. Make emissive mask independent from albedo. Restrict highlights to warm edges and windows; protect 70%+ dark composition as reference heuristic, not artistic approval.
4. Add animated caustic rays, bubbles and haze as low-cost procedural layers; benchmark mobile GPU.
5. Rig fish with tail/fin harmonic articulation; jaw with opening, anticipation, tooth clearance and depth approach. Avoid static-image translations as a substitute for animation.
6. Stage 14 creatures × 5 evolutionary stages; validate transitions, atlas availability and individual animation tests.
7. Capture original-versus-candidate screenshots on all five zones, portrait touch and desktop; compare edge density, amber emissive occupancy, silhouette readability, draw calls, GPU memory, FPS and frame pacing.
8. Roll out behind a candidate/preview path, independent review, no changes to canonical owner HTML until accepted.

## Acceptance targets
- Original canonical HTML SHA unchanged.
- Distinct foreground/midground/background moving at separate parallax speeds.
- 14×5 manifest passes; visual animation verified with time-separated frames, not only metadata.
- Jaw threat visibly opens/closes and moves toward camera without covering hero unexpectedly.
- Software Chromium baseline and physical iPhone tests clearly distinguished.
- No unjustified FPS increase claim, no blind merge.
