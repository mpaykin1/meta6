## Процедура защиты

Каждая строка имеет конкретный короткий тест (не более 600 шагов виртуального времени) в `tests/accepted`. Нельзя удалять строку или ослаблять тест без формального одобрения Claude, подтверждённого текстом владельца. Любой PR в `main` запускает `three-worlds-gate.yml`, включая все accepted tests; красный тест блокирует слияние. Оригинальные `underwater-world/`, V5–V7 неизменяемы.

Красный контроль новой регрессии фиксируется отдельным запуском на виновном коммите, затем `git bisect` ищет первый сломавший commit; исправление обязано быть минимальным. Запрет общего рефакторинга `underwater-runtime.js`, `seabed.mjs`, `camera-rig.mjs`, `hero-controls.mjs`, `transport` при побочном этапе. Перед PR — перечислить все затронутые Axx.

**Важно:** часть тестов фиксирует модель/контракт и дополняется живыми браузерными тестами; соответствие глубокого погружения камеры, водных боевых кнопок и дождя нельзя утверждать без живой проверки владельца. Этот реестр не заменяет отдельные незакрытые задачи §21.22–21.23.

**Зелёный тест на модель не закрывает строку со статусом «ОТКРЫТ ДЕФЕКТ».** Такой дефект закрывают только живой прогон по §20.4 и явное слово владельца.
