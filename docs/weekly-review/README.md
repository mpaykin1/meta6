# Еженедельный аудит Claude + владельца

Здесь появляются реальные датированные ревью `YYYY-MM-DD.md`. README — инструкция, **не вердикт и не отчёт**. Отсутствие отчёта не означает отсутствия дефектов или согласия владельца.

## Структура датированного ревью
- Время UTC и проверенные точные SHA meta6/main и World_server/master.
- PR за неделю, цель каждого, реальные изменения, ссылка на дифф.
- Ассеты/анимация/FPS: сопоставимые замеры, p95 frame time (мс), доказательства скриншотами заката и ночи.
- По трём играм: достигнуто, не подтверждено, визуально ухудшилось, регрессии.
- Ошибки тестов и обещаний, включая false-green и отсутствие живого кадра.
- **Приоритетные задания автозадачам**: нумерованная очередь, конкретный файл/сцена/критерий/источник, статус открыто/закрыто. Следующая weekly-review может отменить старое задание явно.
- Разногласия с `docs/development-memory/`: какие события нужно подтвердить, дополнить или supersede.
- Отдельно: прямой ответ владельца (только если действительно получен в чате) и ссылка на соответствующий контекст. Не подменять оценкой Claude.

Еженедельная сводка, подготовленная одной из пяти автозадач без Claude, должна быть помечена `DRAFT — независимая проверка не проведена`. Только Claude подтверждает собственное ревью; только владелец оценивает игру.
