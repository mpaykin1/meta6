# Урок: сборщик должен разрешать пути относительно скрипта

Дата: 2026-10-20. Источник: PR #135/#136.

Сборщик использует путь к исходной игре, заданный для конкретной машины, а atlas, дополнительные JS и выходной index.html ищет относительно текущего каталога запуска. Скрипт иконок тоже зависит от CWD. Повторная сборка в обычном checkout поэтому не воспроизводима.

Правило: вычислять корень проекта от расположения скрипта, явно разрешать все входы/выходы и проверять сборку из чистого checkout. Это урок о воспроизводимости, не вердикт владельца.
