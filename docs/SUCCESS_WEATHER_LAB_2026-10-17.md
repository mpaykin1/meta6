## Что заработало

- Один HTML с встроенным кодом WebGL и графическими атласами; нет runtime-зависимости от CDN.
- Одна кнопка циклически переключает **11 погодных режимов** с разными атмосферой, частицами и освещением: осенние листья, пять ветров из лепестков (белый, красный, чёрный, розовый, разноцветный), снег, светлячки, гроза и фантастические режимы.
- Настоящая перспективная 3D-сцена острова, рельеф, растительность, башня и вода; 2.5D многокадровые FX расположены в 3D-пространстве.
- Сцена управляется мышью и touch; не требует установки или сети после сохранения файла.
- В предыдущем цикле тестировали переключатель во всех **11/11** режимах, отсутствие ошибок JS в desktop и mobile emulation с программным WebGL. Указанная ранее матрица заметности **98/100** — результат локальной проверки демонстрации, а не аппаратный benchmark и не характеристика всей игры.

## Рецепт повторного применения (AI/Codex/Claude)

1. Прочитать `graf.md` целиком. Выбрать принятый baseline игры и **не перезаписывать** его.
2. Создать два независимых состояния в одном WeatherController: `weatherMode` (частицы, ветер, интенсивность, lifetime) и `lightingPreset` (ambient, directional, fog, sky, flash). На переключении синхронно менять оба.
3. Использовать **детерминированные** procedural-параметры для разнообразия листьев/лепестков. Запекать многокадровые 2.5D листы **offline**, хранить кадр/ракурс/размеры в manifest. При необходимости 8 направлений × 8 фаз.
4. Группировать прозрачные частицы общими атласами, не выделять индивидуальную WebGL-текстуру на каждую снежинку/лист. Пул частиц и разные бюджеты на mobile/desktop; глубина и alpha должны сохраняться.
5. **Встраивать** weather FX в существующий игровой рендер и кадр, а не копировать второй loop/renderer/composer. Здесь автономная демонстрация использует **WebGL напрямую**, не Three.js. Для Three.js необходимо адаптировать шейдер/атласы в существующий Three.js pipeline, а не копировать файл целиком.
6. Тестировать: реальные изменения на холсте после переключения каждого режима, shader compile/link, различимость осенних листьев/5 цветов лепестков/снега/светлячков, mobile viewport без скролла, memory growth, fps p50/p95, низкое энергопотребление. E2E mobile simulation ≠ физический iPhone 11.

## Чему научились

- **Ошибка:** в первой версии был GLSL shader-compile сбой в браузере; тест, который ограничен HTML/JS-синтаксисом, не заменяет WebGL render test. **Исправление:** тестировать создание программ, отрисовку scene и полную циклическую смену эффектов на реальном WebGL context.
- **Ошибка среды:** headless browser не создавал WebGL context; локальный HTTP и программный WebGL дали воспроизводимый browser smoke. **Вывод:** отличать ограничения тестовой машины от ошибок игры, не присваивать режиму PASS по отсутствию исключений.
- **Мобильная компоновка:** при portrait отрегулировали дистанцию орбитальной камеры, чтобы объёмный остров помещался без обрезания.
- **Размер/автономность:** общий многокадровый atlas + встроенные данные делают переносимый единый HTML; проверять файл после сборки, а не только исходный template.
