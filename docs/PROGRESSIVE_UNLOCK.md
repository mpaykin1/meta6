# ПОСТЕПЕННО — правило открытия мира по шагам (все игры)

Пароль `postepenno`. Короткая версия — в [AGENTS.md](../AGENTS.md), раздел «ПОСТЕПЕННО». Здесь — подробности и пример.

## Зачем
Если все враги, оружие и объекты появляются сразу, на экране визуальный хаос: игрок не видит цель (например, луч над нужным предметом) и не понимает, что важно. Мир должен раскрываться постепенно, как сказка: каждый шаг — одна новая вещь, которую игрок успевает заметить, понять и полюбить.

## Правила
1. **Пустой старт.** 1 враг, 1 оружие (+ базовая атака), 1 объект мира. Остальное скрыто, но не удалено.
2. **Таблица `UNLOCK`.** Одна таблица в коде: шаг прогресса → что открывается (враг / оружие / объект / житель / способность). Шаг — это этап роста главной цели, уровень, волна или победа над новым видом врага.
3. **Польза и угроза.**
   - Объект: даёт герою возможность (лечение, ресурс, укрытие, ускорение, обзор, помощник, воскрешение…).
   - Враг: мешает по-своему, у каждого вида своя роль.
   - Первая победа над видом врага: трофей (оружие, реликвия, способность) из уже имеющихся ассетов.
4. **Успехи.** Счётчики побед и действий → именной успех с небольшим постоянным бонусом.
5. **Сообщения.** Пиксельный шрифт игры, ~3 с, плавно появляются и исчезают, очередь по одному:
   - «Новый враг «Название» вышел на охоту»
   - «Открыт новый объект «Название»: даёт …»
   - «Новое оружие: Название»
   - «Трофей: Название — …»
   - «Успех: Название — …»
   Это единственное исключение из правила ЧИСТЫЙ ЭКРАН.
6. **Меню (☰, правый верхний угол).** Разделы: Враги · Оружие · Объекты · Жители · Способности и трофеи · Успехи. В разделе только открытое: иконка, название и правила (что делает, как помогает или мешает, чем побеждать, какой трофей). Закрытое — силуэт или замок без названия. Новое — с точкой, пока раздел не открыт. Текст только внутри меню.
7. **Сохранение.** Открытое сохраняется вместе с прогрессом (Playgama — только `bridge.storage`). Проигрыш с полным перезапуском сбрасывает лестницу, если правила игры не говорят иначе.
8. **Проверка.** На старте ровно 1 враг, 1 оружие, 1 объект. Каждый шаг открывает записанное в `UNLOCK`, показывает сообщение и добавляет запись в меню. Ассетов не стало меньше (скрытые считаются): «было N, осталось N».

## Пример: «Сумерки и пепел II», остров «Пепельный путь» (дерево растёт 30 этапов)
Старт: Вышка, Палка, Мародёр.

| Этап | Объект → что даёт | Враг → чем мешает |
|---|---|---|
| 0 | Вышка → карта острова | Мародёр → рубит ствол |
| 2 | Костёр → восстанавливает сердца рядом | — |
| 3 | — | Пепельный червь → грызёт корни (дерево теряет воду) |
| 4 | Бочки и ящики → вода для лейки, монеты | — |
| 5 | — | Дрон-квадро → обрывает листья (рост откатывается) |
| 6 | Рыбак → лейка на 4 порции | — |
| 8 | Фонари → ночью светло, дроны и тени обходят свет | Солдат пустоши → стреляет в того, кто поливает |
| 10 | Водонапорная башня → раз в минуту полная лейка | — |
| 11 | — | Дрон-глаз → обрывает цветы |
| 12 | Забор → враги идут к дереву медленнее | — |
| 13 | — | Турель → стоит у дороги к воде |
| 14 | Колючие кусты → ранят врагов | — |
| 15 | — | Шагоход-разведчик → сильно бьёт ствол |
| 16 | Могильный крест → один раз воскрешает | — |
| 18 | Светящиеся грибы → 20 с быстрого бега | Странник → крадёт воду из лейки |
| 20 | Призрак смотрителя → подсказки | — |
| 21 | — | Шагоход «Курица» → очень сильно бьёт |
| 22 | Радар → показывает, откуда идут враги | — |
| 24 | Своя турель → стреляет по врагам у дерева | — |
| 25 | — | Колосс → трясёт землю, листья опадают |
| 26 | Руины стены → укрытие | — |
| 28 | Маяк → дерево не сохнет 30 с | — |
| 30 | — | Великан-лесоруб (робот, увеличенный) → пришёл срубить дерево |

Трофеи за первую победу: Мародёр → Кинжал; Червь → «Сосуд душ»; Дрон-квадро → Рогатка; Солдат → Револьвер + «Соколиный глаз»; Дрон-глаз → «Перо чайки»; Турель → «Железная хватка»; Шагоход-разведчик → Тесла-жезл; Странник → «Семя сердца»; «Курица» → Ракетомёт; Колосс → Плазмаган + «Штормовое стекло». Остальное оружие — находки, по одному на каждом втором этапе.

Успехи: Защитник корней (10 врагов у дерева → рост +10 %), Водонос (25 поливов → лейка наполняется быстрее), Охотник на дронов (10 дронов → дроны реже), Гроза шагоходов (5 шагоходов → удары по большим сильнее), Садовник (5 этапов без жажды ниже половины → двойной подарок).
