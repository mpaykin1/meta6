# Дневные отчёты пяти существующих автозадач

Каждый PR должен иметь запись в `YYYY-MM-DD.md` (время UTC), со ссылкой на этот PR.

## Запись одного PR
| Поле | Значение |
|---|---|
| Запуск | дата UTC и слот :05/:15/:30/:40/:50 |
| Репозитории | точные SHA meta6/main, World_server/master |
| Игра / ветка / PR | ссылка, один эффект/изменение |
| Изменено / защищено | что меняется, что не трогается |
| Условия измерения | seed, сцена, настройки, разрешение, устройство/SwiftShader |
| Средний FPS | до / после / разница; UNKNOWN при отсутствии замера |
| p95 frame time | до / после, мс; не путать с p95 FPS |
| Анимация | кадров до / после и изменение фазы |
| GPU стоимость | draw calls и треугольники до / после либо UNKNOWN |
| Визуальный контроль | живые кадры одной камерой в закат и ночь, ссылки |
| Проверки | CI workflow, registry errors, console errors, золотые SHA-256 |
| Неудачи/откат | измеренный отрицательный результат, причины |
| Память | id события из events.jsonl или причина, почему нового урока нет |
| Следующее действие | конкретный небольшой шаг |

Не писать художественный вердикт вместо владельца. Не называть работу проверенной без живого кадра/CI. Несуществующие данные фиксировать как `UNKNOWN (причина)`. Сводить 5 слотов по UTC, проверять свежесть main перед каждой записью и не затирать работу другого слота.
