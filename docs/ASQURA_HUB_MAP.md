## Пять точек для снов, без новых экранных кнопок
1. `tapWorker` (1149) — перехват `w.state==='sleep'` до пробуждения.
2. `spawn` (1143) — назначить конкретный dreamId при появлении состояния sleep.
3. `drawOverlays` (1205) — использовать существующий пузырь над головой.
4. `say` (1122) и `drawPortrait` (1123) — четыре реплики через #dlg и #por.
5. `tap` (1305) — сохранить текущий hit-test, передать действие в tapWorker.

Не менять оригинальные изображения, логику лифта, INV, меню и графику.
