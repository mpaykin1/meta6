## Защита от затыков (решение 2026-10-19, постоянное)
Причина прошлых затыков: автозадача брала правило из СТАРОГО раздела (§21.3 п.3 «мёртвая зона» уже отменён §21.7) и открывала намеренно КРАСНЫЙ draft PR (#75), который никто не мог слить. Правила:
1. Приоритет правил: БОЛЬШИЙ номер раздела в docs/THREE_WORLDS_MERGE_RU.md отменяет меньший; слова «отменено/CANCELLED» окончательны. Перед любым PR проверь, что тест опирается на самый свежий раздел.
2. Запрещены красные/draft PR «для разработчика». Нашёл расхождение: напиши ТОЛЬКО заметку handoff/to-claude/NNN-autotask-finding.md (файл, строка, что не так, готовый тест текстом) и пульс. PR открывай только зелёный и готовый к слиянию (§20.13).
3. Перед работой: список открытых PR ai/*; свои старше 1 часа без движения закрой с комментарием; дубликаты не создавай.
4. Не повторяй чужую работу: если developer уже слил тему (смотри последние PR в main), бери следующую по очереди.
5. Одна маленькая измеримая задача за слот, итог одной строкой в пульс.

## Обучение качеству моделей (решение владельца 2026-10-20; часть существующих автозадач)
Цель: GPT-модели догоняют оригинальные модели Claude (Остров сумерек, Пепельный путь, Затонувший город), а затем вместе делаем ещё лучше: детальнее и оптимизированнее.
Этап 1, догнать. За слот выбери ОДНУ GPT-модель (самую слабую по метрикам) и ближайший ЭТАЛОН из оригинальных (reference/, ash-assets.mjs, npc-catalog.js, models/MANIFEST.json). Сними метрики обеих: число частей/вокселей, палитра (цветов), число кадров анимации и ракурсов, треугольники, draw calls, размер файла. Улучши GPT-модель по разрыву (больше деталей: одежда, швы, свет, вторичная анимация) в `three-worlds-game/models-lab/` (не в игре). Таблицу метрик пиши в docs/model-quality.md (одна строка за слот).
Этап 2, превзойти. Когда метрики GPT-модели ≥ эталона на всех пунктах и визуально не хуже (кадры из Node/Playwright в Actions, облачный браузер запрещён), предлагай её в handoff/to-claude/*-model-promo.md; Claude ревьюит и совместно улучшает: ещё больше детали при меньшей стоимости (меньше треугольников/draw calls через инстансинг, атласы, LOD).
Жёсткие правила: до приёмки Claude модели GPT в игру и тем более в гости не попадают (§21.16, graf §27: без самодельных примитивных спутников); эталоны не менять; оригиналы не копировать как есть под видом новых — учиться приёмам (детализация, анимация, освещение); один небольшой шаг за слот, без дублей; PASS/FAIL только владелец.
