## Запрет облачного браузера (важно)

Если всё же появился диалог доступа — выбери «Отказаться» и продолжай кодом.

## Защита от затыков (решение 2026-10-19, постоянное)
Причина прошлых затыков: автозадача брала правило из СТАРОГО раздела (§21.3 п.3 «мёртвая зона» уже отменён §21.7) и открывала намеренно КРАСНЫЙ draft PR (#75), который никто не мог слить. Правила:
1. Приоритет правил: БОЛЬШИЙ номер раздела в docs/THREE_WORLDS_MERGE_RU.md отменяет меньший; слова «отменено/CANCELLED» окончательны. Перед любым PR проверь, что тест опирается на самый свежий раздел.
2. Запрещены красные/draft PR «для разработчика». Нашёл расхождение: напиши ТОЛЬКО заметку handoff/to-claude/NNN-autotask-finding.md (файл, строка, что не так, готовый тест текстом) и пульс. PR открывай только зелёный и готовый к слиянию (§20.13).
3. Перед работой: список открытых PR ai/*; свои старше 1 часа без движения закрой с комментарием; дубликаты не создавай.
4. Не повторяй чужую работу: если developer уже слил тему (смотри последние PR в main), бери следующую по очереди.
5. Одна маленькая измеримая задача за слот, итог одной строкой в пульс.
