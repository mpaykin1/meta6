# INK · Павший великан — эталон (OWNER PASS, 13.11.2026)

Решение владельца 13.11.2026: «Супер. Это пасс. Размести этот мир на гит МГЛ как эталон», затем «расширь мир… перенеси в тот же артефакт» и «добавь в эталон на МГ и МГЛ».

Смотреть: https://mpaykin1.github.io/meta6-lab/reference/ink-fallen-guardian/ (МГ: https://mpaykin1.github.io/meta6/reference/ink-fallen-guardian/)

## Что принято
- Большой мир INK «Долина дождя»: город, осенний лес, озеро с причалом и лодкой, поляна с мельницей, олень, лиса, каменные ворота, дождь, туман, джойстик/WASD, меню ☰.
- Павший великан — объёмный заросший робот, наполовину в земле (`ink-fallen-robot.js`), лежит на поляне в осеннем лесу (-10.5, 5.8) лицом к камере; деревья вокруг и перед ним расчищены; глаза медленно «дышат» светом. В меню ☰ — зона «Павший великан» и показ робота отдельно.
- **БЕЗ ПАТТЕРНОВ:** в `shared/living-watercolor-3d.js` этой папки пятна акварели считаются шумом (value noise + fbm + искривление координат + медленный дрейф), а не суммой синусов. Сумма синусов давала одинаковые косые пятна по всему миру — владелец это отклонил. Цвета, мазки, обводки не изменены.

## Правила
1. Папка самодостаточна (Three.js 0.165.0 MIT лежит рядом, `three.module.js`). Все файлы — только чтение, защищены `.github/protected/paths.txt`. Меняет только Claude по слову владельца.
2. Новые миры и робот v2 — в отдельных папках/ветках, этот эталон не трогать.
3. Для новых акварельных миров брать рендер из ЭТОЙ папки (версия без паттернов), а не старый `demos/living-watercolor/shared/` (там остался узор).
4. Источник: Claude-артефакт «INK · Павший великан» (13.11.2026) = продакшн `demos/living-watercolor` МГЛ + робот из PR #283 + правка шума.
