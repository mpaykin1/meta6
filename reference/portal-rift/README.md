# Портал гостей: утверждённый эскиз (владелец: «этот портал одобряю», 2026-10-18)
Файл `portal-sketch.html`: автономная WebGL-страница (один фрагментный шейдер, 320x200, масштаб пикселей без сглаживания). Открой в браузере, посмотри 12-секундный цикл.
Это ЭСКИЗ ВИДА, не код игры. Портировать в Three.js: плоскость-щель (ShaderMaterial, форма щели из функции r в шейдере), искры Points + AdditiveBlending, свет PointLight от щели, пиксельная постобработка основного renderer. Одного renderer и одного loop (не копировать requestAnimationFrame эскиза).
Форма: вертикальная рваная щель, края как порванная бумага (бледные волокна, бирюзовая горячая кромка, отогнутые лоскуты), внутри другой мир. Не круглый, без арки.
Цикл: дрожь (предупреждение) -> раскрытие -> гость выходит из глубины на землю -> щель закрывается -> арка гостя.
