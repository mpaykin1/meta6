# World Server Free Cloud — MVP (не принят)

Статус: технический прототип, ожидает решения владельца PASS/FAIL. Принятые игры не изменены.

## Уже работает
- Статический хаб с прямыми ссылками на подводный мир и Observer World V7.
- Локальное сохранение тестового события в браузере.
- Cloudflare Worker с /health и /event (валидация без сохранения).

## Пока НЕ подключено
- Oracle Cloud: нужен созданный владельцем Always Free VM; не гарантирована доступность.
- Supabase: нужны URL и ключи, секреты только на сервере.
- Worker: нужно развернуть в аккаунте Cloudflare; без этого health-кнопка честно сообщает об отсутствии API.
- Межмировая синхронизация, аутентификация и постоянные сохранения не реализованы.

## Проверка
1. Открыть GitHub Pages /free-cloud/ после слияния PR.
2. Проверить обе ссылки на игры.
3. Нажать «Сохранить событие»; обновить страницу, проверить localStorage через консоль.
4. Развернуть worker.js в Cloudflare Worker, задать ALLOWED_ORIGIN=https://mpaykin1.github.io.
5. Открыть /free-cloud/?api=https://<worker-domain> и нажать «Проверить API».
6. Не записывать PASS или FAIL без вердикта владельца.
