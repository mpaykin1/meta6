## Что это за игра
Classic, разросшийся в бесконечный архипелаг: плавание между островами, кит, который выныривает в замедлении и падает на героя, искры от клятв оружия (лечение → щит → фонарь), генератор маяков с разными условиями; зажжённые маяки отодвигают сумерки.

## Исходная заметка сборки

Built on Twilight Isle Classic 1.1.0 (all R1–R10 retention fixes kept, see docs/PLAYGAMA_RETENTION.md).
