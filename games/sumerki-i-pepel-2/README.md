## Что это за игра
Воксельный остров (основа — «Остров сумерек» + «Пепельный путь»). Новая часть, сделанная Claude:
1. **Заставка-сон:** на пустом острове из семечка вырастает волшебное дерево (мох, плющ, лианы, цветы, фрукты, попугаи), корни оплетают остров, дерево становится больше острова, мир переворачивается. Подписи «Мне что, это опять снится?» и «Я должен был найти семя волшебного дерева…». Кнопка ⏭ пропускает заставку.
2. **«Спаси дерево»:** герой просыпается на пустом острове, находит семя (его охраняет страж), сажает его, находит лейку, носит воду с берега и поливает дерево. Враги игры мешают дереву, каждый по-своему. 30 этапов роста, жажда дерева (ряд листьев), подарки на этапах, финальный босс Великан-лесоруб, переворот мира.
3. **ПОСТЕПЕННО:** в начале только земля, пепел и цель; 1 враг и 1 оружие. Объекты открываются победами по одному, подсвечиваются (луч, кольцо, стрелка), при первом контакте объясняют пользу. Враги и оружие — по этапам дерева. Трофеи за первую победу над каждым видом, 5 успехов, меню ☰ с разделами.

## Как проверять (для бота META GAMES)
Открыть игру → «Начать» → заставка (или ⏭) → на старте: 0 объектов, 0 травы, 1 враг (Мародёр-страж), 1 оружие (Палка) + кулаки → победить стража → появилась Вышка (оранжевый луч) → подойти к семени → фраза про посадку → посадить в центре → найти лейку → набрать воду у берега → полить дерево → жажда (листья) растёт, этап дерева растёт.
